## 3. Calibration

### Pass Labels

- `H1` = heavy rewrite
  - placeholder stack overwhelms the scene
  - clean the prose before adding any bridge logic
- `H2` = guided rewrite
  - scene architecture is usable, but diction remains over-explanatory or templated
- `M1` = medium pass
  - chapter largely works
  - strengthen agency, uplift, and implicit bridge signals
- `L1` = light pass
  - preserve current architecture
  - only polish, tighten, and reserve decoder surfaces for app / glossary later

### Global Findings

1. **Book 1 has the clearest early-draft pressure.**
   - The dramatic scaffolding is strong.
   - The diction still carries too much placeholder protocol language.
   - The right move is not to add more lore. The right move is to convert generic system-talk into sharper witness / signal / coherence / choice language.

2. **Book 2 is the richest Noesis bridge zone and the noisiest prose zone at the same time.**
   - Chapters like `The Debug Protocol` and `The Anamnesis Engine` clearly want the Noesis runtime / debugging / compassion-systematized framing.
   - They are also currently the most saturated with placeholder terminology.
   - This book should be treated as the main rewrite harvest, not the place to preserve raw draft diction.

3. **Book 3 is already the tonal calibration target.**
   - The later chapters sound closer to the desired end-state: more coherent, more authored, less over-explained.
   - Book 3 should function as a north star for the pass, especially Chapters 23, 24, and 26.
   - Its phase logic should now be treated explicitly as `MASTERY — Recursive Self-Conscious Authorship`: self-consciousness recursive enough to inspect its own arising, movement from inherited runtime toward source-level authorship, Euclidean consciousness models giving way to Noesis in non-Euclidean space, and shadow / karma integration as the reservoir of samskara.

4. **Explicit blog URLs do not belong in the narrative body.**
   - They belong only in glossary / backmatter / webapp context surfaces / mobile decoder surfaces / editorial admin mapping.
   - The manuscript body should carry concept echoes, not outbound behavior.
